它是怎么跑起来的

核心思路：绕开 SELinux，把 JVM 跑进 App 进程

  1. 为什么手机上不能直接开服？安卓系统（尤其 MIUI）用 SELinux 拦截 exec，直接执行 java -jar 会失败。
  2. McKaiFu 怎么做？打包一份针对安卓原生 libc 编译的 OpenJDK，启动时通过 JNI 把 JVM 的 .so 逐个加载进 App 进程，直接调用 JLI_Launch()。
  3. 结果？整个服务器跑在 App 内部，从不触发 exec，SELinux 管不到——无需 root。
