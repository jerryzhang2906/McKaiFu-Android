## 三、素材拍摄清单(真机操作步骤)

> 横屏拍摄:手机进 App 后横屏(或剪映里旋转 90°)。建议用系统自带「屏幕录制」(设置-更多设置-屏幕录制,开高清+麦克风关)。
> 以下每个"镜头"单独录一段,方便剪辑。

### 镜头 A: 首页展示(0:38-0:45 用)
1. 打开 app(已装 1.20.4 + 1.21.11 两个服务器)
2. 首页服务器列表上下滑动一下,展示两张卡片
3. 停 3 秒,结束录制

### 镜头 B: 一键启动(0:45-0:55 用)
1. 点 1.21.11 服务器卡片 → 进详情
2. 点「启动」
3. 控制台日志开始滚动(Paper 输出)
4. 录到出现 `Done` 字样
5. 结束录制(这段后面剪快)

### 镜头 C: 后台常驻(1:05-1:10 用)
1. 服务器启动中,按 Home 键回桌面
2. 展示后台卡片(可下拉通知栏显示前台服务)
3. 3 秒后结束

### 镜头 D: 创建向导 - 核心类型(1:10-1:17 用)
1. 首页 → 「创建服务器」
2. 核心类型下拉,依次展开 Paper/Purpur/Pufferfish/Spigot/原版/Nukkit/PocketMine
3. 结束

### 镜头 E: 版本选择(1:17-1:24 用)
1. 创建向导里点「版本」
2. 对话框弹出 25 个版本列表,快速滚动
3. 结束

### 镜头 F: Java 运行时(1:24-1:31 用)
1. 设置 → Java 运行时
2. 展示 17/21/25 三个已装/可装状态
3. 结束

### 镜头 G: 内网穿透(1:31-1:38 用)
1. 服务器详情 → 穿透
2. 展开 Playit / Ngrok / NATAPP / 樱花frp 列表
3. 结束

### 镜头 H: 控制台/指令(1:38-1:45 用)
1. 服务器运行中 → 控制台
2. 输入 `list` 或 `tp` 等指令,回车
3. 展示输出
4. 结束

### 镜头 I: 玩家管理(1:45-1:52 用)
1. 服务器详情 → 玩家管理
2. 展示在线玩家列表/踢出/封禁按钮
3. 结束

### 镜头 J: 世界管理/备份(1:52-1:59 用)
1. 服务器详情 → 世界管理
2. 展示世界列表/备份按钮
3. 结束

### 镜头 K: 插件(1:59-2:06 用)
1. 插件商店 → 搜索/浏览
2. 展示插件列表
3. 结束

### 镜头 L: 定时任务(2:06-2:13 用)
1. 设置/服务器详情 → 定时任务
2. 展示定时重启/开关计划
3. 结束

### 镜头 M: 网页地图(2:13-2:20 用)
1. 服务器详情 → WebMap
2. 展示浏览器打开世界地图
3. 结束

### 镜头 N: 收尾(2:20-2:34 用)
1. app 首页,服务器运行中状态
2. 切到 GitHub 仓库页面截图(手机浏览器打开 github.com/jerryzhang2906/McKaiFu-Android)
3. 结束

## 四、剪辑提示

- **卡点**: 第 3 幕功能快剪,每个镜头对准 BGM 鼓点切入(剪映自动节拍检测)
- **转场**: 快剪用「闪白」「抖动」「缩放」;钩子段用「黑场」
- **字幕样式**: 全屏大字白字 + 黑描边,字号 ≥ 标题栏,放画面中央偏下
- **速度**: 启动/日志滚动段落 1.5-2x 加速;装X段正常速
- **结尾**: GitHub 链接字幕停留 ≥ 3 秒,建议右下角加一个常驻角标
